# Expense Tracker (React Native + Expo)

A simple expense tracker that saves your spending on the device and shows a
category-wise bar chart.

## Features
- Add expenses with an amount, optional note, and category
- Running total at the top
- Bar chart of spending by category
- Delete any expense
- Data is saved on the device (AsyncStorage), so it stays after closing the app

## Tech Stack
- React Native + Expo
- @react-native-async-storage/async-storage for local storage

## Run it
1. Install Node.js
2. `npm install`
3. `npx expo start`
4. Scan the QR code with the Expo Go app
